# Security

Privately report reproducible security issues to **contact@biyikgokhan.com**. Do not post live credentials or private references in public issues. Response times depend on maintainer availability.

The wizard’s local development server binds to 127.0.0.1. Reference previews stay in browser memory and are excluded from ZIP export. The wizard does not call AI providers. The optional harness sends data to the provider you configure; review its input and keep credentials in ignored local environment files.

MCP runs over local stdio with no filesystem, network or publishing tools. It transforms data passed by its client; it is not a remote authenticated service.

Checks are not a guarantee against every secret or licensing problem. Review public manifests, URLs, content and history before publishing. Never put API keys in browser code or place.json.
