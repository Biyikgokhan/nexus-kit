# <Mekân adı>

Editable Nexus Interlink source project. Requires Node.js 22.12+.

```sh
npm install
npm run dev
npm run build
```

Set your real HTTPS URL and edit `place.json`. Building validates the public data and regenerates both manifests. Deploy `dist/` including `.well-known/` to your domain. This is an orbitable procedural room; replace it with a GLB exported to `public/models/place.glb` through the page button.

References in `reference/photos/` and `reference/sketch.*` stay out of Git. Never add credentials to place.json or browser code. Optional agent instructions in `harness/` are GPL-3.0-or-later; site templates are Apache-2.0 (see LICENSE). Your original art remains yours.

## Türkçe

Node 22.12+ ile npm install, npm run dev, npm run build komutlarını çalıştır. place.json içindeki HTTPS adresini ve mekânını düzenle; derleme manifestleri yeniler. dist/ klasörünü .well-known/ dahil kendi alan adına yükle. Sayfa TR/EN arayüz sunar. Özgün içerik otomatik çevrilmez; translations.tr ve translations.en içinde name/description ekleyebilirsin. Fotoğraf, özel adres ve anahtarlarını herkese açık dosyalara koyma. Atlas kaydı ayrı bakımcı incelemesi gerektirir.
